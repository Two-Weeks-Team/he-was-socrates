Demo modes — recap

The bust auto-detects mode from the first user utterance via Gemma function-call mode_classify. UI signals the active mode with a chip: curious_adult learning_student plus iconography (per SC1 a11y, color alone insufficient).

Files behind this page — generated entirely by build-time Python tools (Pillow + numpy): scripts/halftone.py · scripts/viseme_compose.py · scripts/build_manifest.py · Makefile. Determinism check: make assets-verify rebuilds and fails on byte-drift. Runtime ships only the 17 generated PNGs in the .app bundle; Python toolchain stays in the repo, never in DMG.
