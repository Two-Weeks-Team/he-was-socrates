# assets/

Build-time and runtime visual asset directory.

## Files in this directory

| File | Origin | Persisted? | Used by |
|---|---|---|---|
| `source-portrait.png` | User AI-generated, painterly Socrates | **YES — pending user upload next turn** | `scripts/halftone.py` (build-time only) |
| `face_halftone.png` | GENERATED by `scripts/halftone.py` | yes (committed) | runtime: BustView idle/REST viseme |
| `visemes/viseme_*.png` | GENERATED by `scripts/viseme_compose.py` | yes (committed, 16 files) | runtime: BustView 30fps swap |

## Pipeline

```
source-portrait.png  ──[scripts/halftone.py]──>  face_halftone.png
                     ──[scripts/viseme_compose.py]──>  visemes/viseme_*.png  (16)

Output is checked into Git (small 1-bit PNGs ≈ 50-200 KB each, total < 5 MB).
```

## Determinism

`build-visemes.sh` records SHA-256 of every output PNG to
`.build-manifest.json`. CI verifies the manifest is unchanged across
rebuilds. If you re-run the pipeline and the manifest changes, your
halftone parameters or source portrait differ from the committed state —
investigate before committing.
