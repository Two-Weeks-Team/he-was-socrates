# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of conduct.

The full text is published at:
**https://www.contributor-covenant.org/version/2/1/code_of_conduct/**

A plain-text reference copy is also available at:
**https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt**

## Scope

The Contributor Covenant applies within all project spaces — this repository, its
issue tracker, pull requests, discussions, and any communication channels related
to the project (email, future Discord/Slack, conference presentations of the work).
It also applies when an individual is officially representing the project in public
spaces.

## Reporting

To report a concern, contact the maintainer:

- **Email:** `app.2weeks@gmail.com`
- **Subject line prefix:** `[he-was-socrates conduct]`
- **Acknowledgment:** within 7 days
- **PGP key:** not yet published; report contents will be transmitted in plain text
  unless you propose an alternative

All reports will be handled with discretion. Reporters' identities will be kept
confidential except where the response requires disclosure (e.g., when a remediation
involves another community member's awareness). The reporter will be informed before
any disclosure occurs.

## Enforcement guidelines

Enforcement follows the four-stage progression specified in
**Contributor Covenant 2.1, "Enforcement Guidelines"** (Correction → Warning →
Temporary Ban → Permanent Ban). The maintainer applies the level appropriate to
the violation. The full enforcement guidelines are at the URL above.

## Why we adopt this verbatim

The Contributor Covenant is the de-facto standard adopted by tens of thousands of
open-source projects. Adopting it without modification means contributors who have
encountered it elsewhere can rely on the same expectations here. Project-specific
deviations would be more confusing than helpful.
