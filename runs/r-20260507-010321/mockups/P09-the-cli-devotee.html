2. socrates(1) — synopsis & options

man socrates — less — 96×30 SOCRATES(1) 
NAME
     socrates – the Korean Socratic bust, on-device, in your terminal

SYNOPSIS
     socrates [-q] [--lang ko|en] [--mode repl|once|json] [--no-tts] [QUERY]
     socrates ask     "<query>"
     socrates repl
     socrates recall  [--since YYYY-MM-DD]
     socrates --setup | --doctor | --version

DESCRIPTION
     A Socratic interlocutor that returns questions, not answers. All inference,
     STT, and TTS happen on the local Mac. Zero bytes leave the device after
     the one-time weight download. The abstention mechanic (⊘ defer_to_human)
     is the product, not a fallback — it has its own exit code.

OPTIONS
flagdescriptiondefault
-q, --quietsuppress status line; emit response onlyoff
--lang ko|eninput/output language for the Socratic turnko
--mode repl|once|jsoninteractive TUI · single turn · machine-readableonce
--no-ttsskip AVSpeechSynthesizer; text-only outputoff
--thinkingshow Phase enum transitions (idle→listening→thinking→…)off
--trace-fcprint raw function-call dispatch from Gemma 4off
--airplanerefuse to start if any network egress is detectableoff
EXIT STATUS
codemeaningfunction
0ask_back returned a Socratic question (success)ask_back
2mode_classify routed to surface_past_wonder; recall printedsurface_past_wonder
3thinking-mode pulse interrupted by user (SIGINT)—
64EX_USAGE — bad flags or empty query—
69EX_UNAVAILABLE — weights missing; run --setup—
77⊘ defer_to_human — medical/legal/financial/welfare/insurance/emergencydefer_to_human
