## §2 — Client component count

| Client component | Why it must be client |
|---|---|
| `<AbstentionDemo>` | Stateful 3-screen sequence with auto-advance and `prefers-reduced-motion` switching. |
| `<CopyButton>` | `navigator.clipboard.writeText()` is a browser API. |

**Total client components: 2.** Every other component renders on the server. This is the dominant lever for the ≤200 KB gzip per-route budget.

## §3 — Forbidden patterns (consequences of SPEC.md.iter7 §3)

The following component-level patterns are **forbidden** by the iter7 NO-DATA-COLLECTION invariant and MUST NOT appear in any component:

| Forbidden | Reason |
|---|---|
| Any `<form>` with `action`, `method`, or `onSubmit` | No user input collected. |
| Any `<input>`, `<textarea>`, `<select>` | Same. |
| `useEffect` calls that `fetch()` | No runtime egress. Build-time fetch in `next build` is allowed. |
| `localStorage.setItem`, `sessionStorage.setItem`, `indexedDB.put` for user-derived data | No persisted state. (Reading `prefers-color-scheme` via `matchMedia` is allowed; that's not persisted user data.) |
| `<script src="https://...">` injected via `next/script` with `strategy="afterInteractive"` from third-party CDNs | No third-party scripts. |
| `<img src="https://shields.io/badge/...">` runtime CDN badges | Replace with build-time-generated static SVGs in `public/badges/`. |
| `<iframe>` to off-origin URLs | No embedded content. |
| `next/script` GTM, Plausible, Umami, Vercel Analytics tag | All analytics forbidden. |
| Service worker registration | Forbidden (no PWA, see `routes.md` §5). |

The build pipeline includes a static-analysis lint (a small `node` script in `scripts/lint-no-collection.mjs`) that grep-greps the `app/` and `components/` trees for these patterns. The lint runs in `pnpm build` and fails the build on any match. See `build.md` §6.

4. The system-prompt parity script passes (Korean text byte-equivalent to the macOS source).
5. The entitlements parity script passes (entitlements XML byte-equivalent to the macOS source).
6. Manual screenshot diff against the source HTML at desktop ≥1280 px and mobile ≤390 px is approved by the user.
