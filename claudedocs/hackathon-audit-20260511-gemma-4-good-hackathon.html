3. Top 5 우선순위 갭

Impact × Effort 매트릭스로 정렬. D-8 마감 대비 처리 권장 순서. 본인(사용자) 직접 처리 외 항목은 팀원 진행 중.

  1. [CRITICAL impact, ~1d effort] 데모 비디오 촬영 + 편집 + YouTube 업로드 — 룰의 hard requirement. 스크립트 이미 있음. 실행 환경에서 OBS/QuickTime 캡처 + 자막 + 음성 narration. 팀원 진행 중 — 상태 동기화 필요
  2. [CRITICAL impact, ~4h effort] DMG 노타라이즈 + GitHub Release 발행 — Apple Developer Program 이미 enrolled. xcrun notarytool submit + stapler staple + gh release create v0.1.0 path/to/HeWasSocrates.dmg. 팀원 진행 중
  3. [HIGH impact, ~2h effort] Kaggle 제출 페이지에 writeup paste + 최종 폴리시 — docs/writeup-draft.md 1,294 단어가 base. Kaggle UI 폼에 맞춰 섹션 트림 + 이미지 임베드. 팀원 진행 중
  4. [MED impact, ~1h effort] 앱 스크린샷 3-5장 캡처 — Preflight · bust speaking · abstention demo · viseme animation · settings. README + writeup + Kaggle 페이지에 임베드. 본인 가능 (macOS native screen capture)
  5. [LOW impact, ~5min effort] PR #38 머지로 README 배지 갱신 — tests 41→65 + macOS 14+→26+ + live preview link. 이미 OPEN 상태. 사용자 승인만 필요
