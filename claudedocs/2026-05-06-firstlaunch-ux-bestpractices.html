요약 (Executive Summary)

핵심 결론 (v2 — macOS 26 floor + 양언어)

floor를 macOS 26 Tahoe로 올리고 한국어와 영어를 모두 첫 실행에 다운로드하기로 결정함에 따라:

  • F2 (STT 자산)이 가장 큰 변화: deeplink 안내 → AssetInventory.assetInstallationRequest(supporting:) in-app 한 번 탭 설치 + Progress 바로 전환. ko_KR + en_US 둘 다 한 요청으로 묶음.
  • F1 (TTS 음성)은 여전히 deeplink: macOS 26에도 AVSpeechSynthesisVoice의 프로그래밍적 설치 API는 추가되지 않음 (Apple Forum #758460 + WWDC25/26 발표 미언급). Yuna(ko-KR) + Samantha(en-US) 둘 다 enhanced/premium은 사용자 수동 다운로드 필요.
  • F4–F7은 다국어와 무관: 권한·진행 표시·pre-flight 패턴 동일.

TTS 음성 미설치 — Yuna(ko-KR) + Samantha(en-US) 양 언어 HIGH

증상: AVSpeechSynthesisVoice.speechVoices()가 ko-KR 0개, en-US는 default 품질만. 양 언어 모두 enhanced/premium은 사용자가 직접 다운로드 필요.

Apple 공식 입장 — macOS 26에서도 변경 없음

Apple Developer Forums Thread #758460: "there appears to be no API for apps to know if enhanced or premium voices are available to download but not yet installed on a device — the only available API is AVSpeechSynthesisVoice.speechVoices() which returns voices already available on the device." WWDC25/26 발표에서도 이를 대체하는 API는 추가되지 않았다. macOS 26 floor에서도 detect → deeplink가 유일한 길.

useyourloaf reference: "Premium quality voice requires you to download it to use, and enhanced quality voice also requires downloading … all preinstalled voices are default quality." — Samantha(en-US)도 default 품질만 사전 설치되며, enhanced/premium 품질은 Yuna와 동일하게 사용자 수동 다운로드.

권장 패턴 (양 언어 동시 detect)

swiftextension TTSManager {
    /// 한국어 + 영어 모두 enhanced 이상 품질의 음성이 설치되어 있는가.
    /// default 품질 fallback은 audio quality가 매우 robotic하여 사용자가
    /// "망가졌다"고 인식 — UX 측면에서 "없는 것과 동일"로 분류.
    public func missingHighQualityVoices() -> [String] {
        let all = AVSpeechSynthesisVoice.speechVoices()
        let needsHQ: (String) -> Bool = { lang in
            !all.contains { $0.language == lang &&
                ($0.quality == .enhanced || $0.quality == .premium) }
        }
        var missing: [String] = []
        if needsHQ("ko-KR") { missing.append("ko-KR") }  // Yuna 권장
        if needsHQ("en-US") { missing.append("en-US") }  // Samantha 권장
        return missing
    }
}

macOS 26 신 패턴 — SpeechAnalyzer + AssetInventory

WWDC25 Session 277 "Bring advanced speech-to-text to your app" + SpeechAnalyzer doc + AssetInventory doc:

swiftimport Speech

// 1. Build transcribers for both locales
let transcriberKo = SpeechTranscriber(
    locale: Locale(identifier: "ko_KR"),
    transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: []
)
let transcriberEn = SpeechTranscriber(
    locale: Locale(identifier: "en_US"),
    transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: []
)

// 2. Single request covering BOTH locales' assets
if let installRequest = try await AssetInventory.assetInstallationRequest(
    supporting: [transcriberKo, transcriberEn]
) {
    // installRequest.progress is a Foundation.Progress — bind to ProgressView
    try await installRequest.downloadAndInstall()
}

// 3. Verify (idempotent — safe to call always)
let installedKo = await SpeechTranscriber.isAvailable(for: Locale(identifier: "ko_KR"))
let installedEn = await SpeechTranscriber.isAvailable(for: Locale(identifier: "en_US"))

지원 locale 확인: ko_KR, en_US 모두 SpeechTranscriber.supportedLocales() 목록에 포함 — callstack tutorial + antongubarenko guide 교차 검증.

Apple HIG의 3가지 명시 규칙

  1. Determinate progress + 의미 있는 라벨 — Apple HIG: "include a label above an activity indicator to give extra context and avoid vague terms like loading or authenticating ... only use progress bars for tasks that are quantifiable" (HIG · Progress Indicators).
  2. URLSessionDownloadTask + resume data — Pausing and resuming downloads: cancel(byProducingResumeData:) + session.downloadTask(withResumeData:). HuggingFace는 Accept-Ranges: bytes + ETag 모두 제공.
  3. Phase-aware 라벨 — 다운로드 페이즈 ≠ 검증 페이즈 ≠ 압축 해제 페이즈. 각 단계가 분리된 라벨을 가져야 함.

핸드오프 T2.1 (가중치 사이드카) 재평가

🚨
사이드카 도입 권장하지 않음

현재 구현은 invariant-preserving이다: GemmaService.swift:120-128의 LLMModelFactory.shared.loadContainer(...)는 OS-mediated MLX 캐시가 다운로드를 수행한다. 앱 자신의 URLSession이 아니므로 com.apple.security.network.client 엔타이틀먼트 없이도 동작한다.

사이드카 도입 시 두 가지 형태 모두 단점이 있다:

  • Bundled-in-DMG (4.5GB): GitHub Releases 2 GiB cap 초과 → R2/B2 호스팅 필요. DMG 다운로드도 결국 외부 CDN. 사용자는 "왜 4.5GB DMG를 받아야 하지?"
  • WeightsDownloader.app sidecar: 별도 노터라이즈 + 별도 사용자 신뢰 프롬프트. 비기술 한국 사용자에게 마찰 2배.

권장: 기존 OS-mediated 다운로드를 유지하고 SwiftUI Progress/ProgressView로 UI만 강화.

3.2 App Sandbox와 시스템 설정 호출

✅

샌드박스 앱에서 x-apple.systempreferences: URL은 추가 entitlement 없이 동작.

Apple Developer Forums Thread #65606 + App Sandbox 구성 가이드: NSWorkspace.shared.open의 시스템 URL scheme 처리는 Launch Services 경유로 등록된 핸들러(System Settings.app)에 위임된다. 샌드박스는 이를 일반적인 cross-app 활성화로 인식 — com.apple.security.temporary-exception.shared-preference.read-write나 다른 임시 예외 entitlement 불필요.

현재 entitlement 확인 (HeWasSocrates.entitlements):

xml<key>com.apple.security.app-sandbox</key><true/>
<!-- com.apple.security.network.client = INTENTIONALLY ABSENT -->
<!-- com.apple.security.network.server = INTENTIONALLY ABSENT -->
<key>com.apple.security.device.audio-input</key><true/>
<key>com.apple.security.files.user-selected.read-write</key><true/>
<key>com.apple.security.files.downloads.read-write</key><true/>

Tier B 모든 권장사항이 위 entitlement 집합 안에서 구현 가능. NO-CLOUD invariant 100% 보존.

제한 사항: CFPreferences*나 defaults write로 시스템 설정 값을 직접 변경하는 것은 샌드박스에서 차단된다 — 시도하지 말 것. 단, 본 보고서의 어떤 권장사항도 이를 필요로 하지 않는다.

6.2 Pre-flight 검사 모듈 (양언어)

새 파일 apps/macos/HeWasSocrates/HeWasSocrates/Preflight.swift 생성 — 엔진 layer가 아닌 앱 layer에 위치:

swiftimport Foundation
import AVFoundation
import Speech

struct PreflightCheck: Identifiable {
    enum Kind: String, CaseIterable {
        case macOSVersion, appleSilicon, diskSpace
        case koreanVoice, englishVoice          // F1 양언어
        case koreanSTT, englishSTT              // F2 양언어
        case gemmaWeights
    }
    let id = UUID()
    let kind: Kind
    let passed: Bool
    let userMessage: String?
    let recoveryDeeplink: URL?
    let inAppInstaller: (() async throws -> Void)?  // F2 AssetInventory
}

enum PreflightRunner {
    static func runAll() async -> [PreflightCheck] {
        async let os    = checkMacOSVersion()
        async let arm   = checkAppleSilicon()
        async let disk  = checkDiskSpace(minBytes: 8 * 1024 * 1024 * 1024)
        async let voiceKo = checkVoice(language: "ko-KR", kind: .koreanVoice)
        async let voiceEn = checkVoice(language: "en-US", kind: .englishVoice)
        async let sttKo = checkSTT(locale: "ko_KR", kind: .koreanSTT)
        async let sttEn = checkSTT(locale: "en_US", kind: .englishSTT)
        async let gemma = checkGemmaWeights()
        return [await os, await arm, await disk,
                await voiceKo, await voiceEn,
                await sttKo, await sttEn,
                await gemma]
    }

    /// F1 — 양 언어 동일 패턴, 단일 deeplink로 양 언어 커버
    private static func checkVoice(language: String, kind: PreflightCheck.Kind) async -> PreflightCheck {
        let voices = AVSpeechSynthesisVoice.speechVoices()
            .filter { $0.language == language }
        let hasUsable = voices.contains { $0.quality == .enhanced || $0.quality == .premium }
        let displayName = language == "ko-KR" ? "한국어 음성 (Yuna 권장)" : "영어 음성 (Samantha 권장)"
        return PreflightCheck(
            kind: kind, passed: hasUsable,
            userMessage: hasUsable ? nil : "\(displayName) — 고품질 다운로드 필요",
            recoveryDeeplink: URL(string:
                "x-apple.systempreferences:com.apple.preference.universalaccess?SpokenContent"),
            inAppInstaller: nil  // TTS는 in-app 자동 설치 API 없음
        )
    }

    /// F2 — macOS 26 SpeechAnalyzer + AssetInventory in-app 다운로드
    private static func checkSTT(locale: String, kind: PreflightCheck.Kind) async -> PreflightCheck {
        let loc = Locale(identifier: locale)
        let available = await SpeechTranscriber.isAvailable(for: loc)
        let displayName = locale == "ko_KR" ? "한국어 음성 인식" : "영어 음성 인식"
        return PreflightCheck(
            kind: kind, passed: available,
            userMessage: available ? nil : "\(displayName) — 자료 다운로드 필요 (~70 MB)",
            recoveryDeeplink: URL(string:
                "x-apple.systempreferences:com.apple.preference.speech?Dictation"),
            inAppInstaller: {
                let transcriber = SpeechTranscriber(
                    locale: loc, transcriptionOptions: [],
                    reportingOptions: [.volatileResults], attributeOptions: []
                )
                if let req = try await AssetInventory.assetInstallationRequest(supporting: [transcriber]) {
                    try await req.downloadAndInstall()
                }
            }
        )
    }

    /// 더 효율적: 두 locale을 한 요청에 묶어 단일 다운로드 세션
    static func installSTTAssetsBilingual() async throws -> Progress? {
        let ko = SpeechTranscriber(
            locale: Locale(identifier: "ko_KR"),
            transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: []
        )
        let en = SpeechTranscriber(
            locale: Locale(identifier: "en_US"),
            transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: []
        )
        guard let req = try await AssetInventory.assetInstallationRequest(supporting: [ko, en]) else {
            return nil  // 자산이 이미 모두 설치된 상태
        }
        // req.progress를 SwiftUI ProgressView(value:)에 바인딩 가능
        try await req.downloadAndInstall()
        return req.progress
    }

    private static func checkDiskSpace(minBytes: Int64) async -> PreflightCheck {
        let url = URL(fileURLWithPath: NSHomeDirectory())
        let values = try? url.resourceValues(forKeys: [.volumeAvailableCapacityForImportantUsageKey])
        let available = values?.volumeAvailableCapacityForImportantUsage ?? 0
        let ok = available >= minBytes
        let gbAvail = Double(available) / 1024 / 1024 / 1024
        return PreflightCheck(
            kind: .diskSpace, passed: ok,
            userMessage: ok ? nil
                : String(format: "디스크 여유 부족 — 약 %.1f GB만 남아 있어. 최소 8 GB가 필요해.", gbAvail),
            recoveryDeeplink: nil, inAppInstaller: nil
        )
    }

    // macOSVersion (≥26.0), appleSilicon, gemmaWeights 체크는 동일 패턴으로 추가
}

6.3 SocraticAppViewModel 확장

swift// ContentView.swift SocraticAppViewModel 안에 추가

enum PreflightStatus: Equatable {
    case idle, running, allReady
    case blocked(missing: [PreflightCheck])
}

enum BootstrapStage: String {
    case downloadingWeights = "Gemma 4 모델 다운로드 중"
    case verifying          = "모델 검증 중"
    case loadingIntoMemory  = "모델 메모리에 올리는 중"
    case warmingUp          = "흉상 깨우는 중"
}

@Published var preflight: PreflightStatus = .idle
@Published var bootstrapStage: BootstrapStage = .loadingIntoMemory
@Published var bootstrapDetail: String = ""
@Published var permissionsRequested: Bool = false

func runPreflightAndBootstrap() async {
    preflight = .running
    let checks = await PreflightRunner.runAll()
    let failing = checks.filter { !$0.passed }
    if !failing.isEmpty {
        preflight = .blocked(missing: failing)
        return  // UI에서 사용자가 해결 후 retry 버튼으로 재진입
    }
    preflight = .allReady
    await bootstrap()
}

// 첫 Spacebar 직전에 호출 — beginListening() 안에서 분기
func requestPermissionsIfNeededThenListen() async {
    if !permissionsRequested {
        // SwiftUI sheet로 explainer 보여준 뒤 호출되도록 분리
        _ = await coordinator.audio.requestPermissions()
        permissionsRequested = true
    }
    beginListening()
}

6.4 사용자가 시스템 설정 갔다가 돌아왔을 때 자동 재검사

swift// AppDelegate에 추가 — 또는 ViewModel init에서 NotificationCenter 등록

override init() {
    super.init()
    NSWorkspace.shared.notificationCenter.addObserver(
        forName: NSWorkspace.didActivateApplicationNotification,
        object: nil, queue: .main
    ) { [weak self] notification in
        guard let app = notification.userInfo?[NSWorkspace.applicationUserInfoKey] as? NSRunningApplication,
              app.bundleIdentifier == Bundle.main.bundleIdentifier
        else { return }
        // 사용자가 우리 앱으로 복귀 — preflight가 blocked 상태면 재검사
        Task { @MainActor in
            if case .blocked = self?.preflight {
                await self?.runPreflightAndBootstrap()
            }
        }
    }
}
